# Description

## One-line (GitHub "About", under 350 characters)

A dated field guide to modern AI: 173 concepts across LLMs, VLMs, agents and harnesses, MCP and other protocols, post-training, inference, AI hardware standards, evals, safety and AI engineering roles (like FDE), each with key points and curated GitHub, blog, paper and spec links. Markdown, HTML, PDF, Word, LaTeX and Excel.

## Short description (one paragraph)

The Modern AI Concept Book explains the vocabulary of modern AI in plain language and keeps it dated. Each of its 173 concepts, from agent harnesses and the Model Context Protocol to on-policy distillation, NVFP4, UALink and the forward deployed engineer, has a definition, key points, a state-of-the-art note for September 2026, and hand-picked resources labelled by type and year. It ships as a GitHub-readable Markdown book with browse-by indexes, an interactive HTML edition with filters by category, year, level, tag and resource type, and PDF, Word, LaTeX (Overleaf) and spreadsheet editions, all generated from one structured source.
